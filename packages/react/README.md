# @virgo-terminal/react

A React terminal component built on xterm.js. It supports interactive input, streaming output, read-only mode, resizing, and appearance settings. The package works with React 18.2 and React 19.

## Install

```sh
npm install @virgo-terminal/react
```

```tsx
import { Terminal } from '@virgo-terminal/react';
import '@virgo-terminal/react/styles.css';
```

Give the terminal container a height when using `autoFit`. See the [usage example](https://github.com/virgo-galaxy/virgo-terminal#use-the-react-component) for a complete echo terminal.
