# @virgo-terminal/react

A React terminal component built on xterm.js. It supports interactive input, streaming output, read-only mode, resizing, and appearance settings. The package works with React 18.2 and React 19.

Import `Terminal` from `@virgo-terminal/react` and load `@virgo-terminal/react/styles.css` alongside it. See the [usage example](https://github.com/virgo-galaxy/virgo-terminal#use-the-react-component) for a complete echo terminal.
